## 二、发现的问题

### 🔴 严重（Critical）

#### P1. 无法退出应用（致命 UX 缺陷）
- **现象：** `app.on('window-all-closed', e => e.preventDefault())` 阻止退出，`skipTaskbar: true` 不显示任务栏，且无系统托盘。用户启动后无法通过任何正常方式退出，只能任务管理器杀进程。
- **影响：** 用户无法正常关闭应用，体验极差，可能误以为程序卡死。
- **文件：** `src/main.js`

#### P2. README license badge 与实际协议不符
- **现象：** README 第 7 行 badge 显示 `license-MIT-green`，但 LICENSE 文件是 Apache 2.0，package.json 也是 `"license": "Apache-2.0"`。
- **影响：** 误导用户对协议的认知，可能影响合规使用。
- **文件：** `README.md`

### 🟡 中等（Medium）

#### P3. 首次启动无任何视觉反馈
- **现象：** `show: false` + `skipTaskbar: true`，用户双击 exe 后看不到窗口也看不到任务栏图标，会以为程序没启动，反复双击导致多实例。
- **影响：** 首次使用体验差，用户困惑。

#### P4. 失焦立即隐藏无 grace period
- **现象：** `mainWindow.on('blur', () => mainWindow.hide())` 立即隐藏。用户切到输入法候选框、字典等辅助窗口时搜索框瞬间消失。
- **影响：** 中文用户输入法切换时搜索框丢失，影响使用流畅度。

#### P5. 无右键菜单
- **现象：** 结果项只支持点击启动，无法"打开所在文件夹""以管理员运行""复制路径"等常用操作。
- **影响：** 功能缺失，无法管理应用。

#### P6. 无 Tab 键补全
- **现象：** 选中后按 Tab 无反应，无法补全到选中项名称继续缩小范围。
- **影响：** 键盘操作效率低。

#### P7. 索引状态无进度反馈
- **现象：** 状态栏显示 "X 个应用已索引"，但首次启动索引需要时间，用户看到 "0 个" 时不知道在加载还是没应用。
- **影响：** 首次使用困惑。

### 🟢 轻微（Minor）

#### P8. placeholder 文案啰嗦
- **现象：** "搜索应用，输入名称开始..." 啰嗦，Spotlight 风格应更简洁。
- **修复：** → "搜索应用..."

#### P9. 选中态背景过鲜艳
- **现象：** `--bg-selected: #c7e0fc` 偏蓝紫，与苹果白柔和调性不符。
- **修复：** → `#e8f0fe`，描边对比度 0.35 → 0.45 提升清晰度。

#### P10. 状态栏蓝点过淡
- **现象：** `opacity: 0.55` 在白底上几乎看不见。
- **修复：** → `0.85`，并加索引中呼吸动画。

#### P11. 空状态 SVG 与搜索框图标完全相同
- **现象：** 空状态用同样的放大镜 SVG，缺乏"没找到"的语义差异化。
- **修复：** 加斜线（opacity 0.5）表示"无结果"。

#### P12. 输入框无 maxlength
- **现象：** 超长字符串可能影响布局。
- **修复：** 加 `maxlength="120"`。

#### P13. 无 Ctrl+Backspace 清空
- **现象：** 很多 launcher 支持一次清空输入。
- **修复：** 新增 Ctrl/Cmd+Backspace 清空。

## 六、遗留可优化项（后续巡检可处理）

1. 全局热键 `Alt+Space` 与 Windows 中文输入法切换冲突，可考虑改为 `Ctrl+Space` 或提供热键自定义
2. 重名应用无法区分（`shortenPath` 只返回位置类型，两个同名应用都在 Program Files 时无法区分）
3. 索引失败无用户可见错误提示（仅 console.error）
4. 无设置窗口（热键自定义、扫描目录配置、主题切换）
5. 无多显示器支持（仅在主显示器居中）
